# browsegit
A mini Rust app that let's you clone your own repositories locally by running

```Browsegit <GITHUB TOKEN>```

how to setup your github tokens: https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/managing-your-personal-access-tokens
cargos used: ratatui, crossterm, tokio, reqwest ...
